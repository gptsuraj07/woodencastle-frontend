How Categories Work

Main Category
Main section shown in website sidebar.

Example: chopping-boards

Sub Category
Optional category inside a main category.

Example: walnut-chopping-boards
teak-wooden-boards

Important
Products with SAME main category will appear together.

Subcategory helps separate products inside that category.

Example Structure 
Chopping Boards
 ├── Walnut Chopping Boards
 │     ├── Tilted Neck
 │     ├── Rustic Edge
 │
 └── Teak Wooden Boards
       ├── Classic Teak
       ├── Chef Board
Adding Product
  • Add main category first
  • Subcategory is optional
  • Upload maximum 4 images
  • Add at least one variant with price
  • Dimensions are optional
Editing Product
  • Click product card on right side
  • Existing images load automatically
  • Remove images using ✕
  • Upload new images if needed
  • Click Update Product
